CharAssist

AI가 다듬고, 당신이 결정한다.

캐릭터 설명, 로어북, 정규식, 트리거, 페르소나까지 — AI와 함께 편집하고, 바뀐 부분을 한눈에 확인하고, 언제든 되돌릴 수 있습니다.

주요 기능

편집부터 검토, 되돌리기까지 하나의 흐름으로.

🖍

바뀐 부분 하이라이트

AI가 손댄 곳만 형광펜으로 표시됩니다. 전체를 다시 읽지 않아도 무엇이 달라졌는지 바로 파악할 수 있습니다.

↩️

언제든 되돌리기

적용한 뒤에도 한 번의 클릭으로 직전 상태로 복원됩니다. 실수가 두렵지 않습니다.

✨

이어서 개선 모드

AI 결과를 바탕으로 추가 요청을 입력해 계속 다듬을 수 있습니다. 처음부터 다시 시작할 필요가 없습니다.

💾

작업 내용 자동 보존

창을 닫아도 AI 결과와 요청사항이 저장됩니다. 나중에 열어 이어서 검토할 수 있습니다.

⭐

즐겨찾는 요청 문구

📌

참고범위 지정

로어북 편집 시 설명을 함께 참고하게 하는 등, 다른 영역을 컨텍스트로 포함해 일관성 있는 결과를 얻을 수 있습니다.

일곱 개의 탭, 하나의 캐릭터.

각 탭은 독립적으로 동작하지만 참고범위로 서로 연결됩니다.

👤 설명

캐릭터의 description 필드를 AI로 다듬습니다. 이름·나이·성별·장르를 지정해 방향을 잡고, 캐릭터 프리셋으로 출력 형식을 통일할 수 있습니다.

이어서 개선 영문 번역 캐릭터 프리셋 장르 선택
📖 로어북

로어북 항목을 선택하거나 새로 만들어 AI로 내용을 작성·보완합니다. 다른 항목과의 일관성을 참고범위로 유지할 수 있습니다.

항목 생성 영문 번역 폴더 제외
🧩 정규식

정규식 스크립트를 JSON 형태로 확인하고 AI로 패턴을 최적화합니다. 구조는 유지한 채 값만 교체합니다.

JSON 편집 패턴 최적화
⚡ 트리거

Lua / V1 / V2 타입을 자동으로 감지합니다. 조건과 효과를 AI로 수정하거나 새 트리거를 처음부터 만들 수 있습니다.

Lua 지원 타입 자동 감지 새 트리거 생성
🎭 페르소나 업데이트

AI로 유저 페르소나를 창작하거나, 기존 페르소나를 선택해 직접 수정하고 바로 저장할 수 있습니다. 장르(12종), 컨셉 힌트, 기본·심화 프리셋을 지원합니다.

신규 생성 기존 편집 · 저장 AI 개선 장르 12종 이어서 개선 영문 번역
🗂️ 이미지 갤러리 NEW

이미지를 업로드해 갤러리에 보관합니다. 페르소나 탭에서 이미지를 선택해 아이콘으로 설정하거나, 리수 페르소나 이미지를 갤러리로 백업할 수 있습니다.

다중 업로드 페르소나 아이콘 설정 JSON 백업 · 복원 리수 페르소나 이미지 연동

AI 공급자 · 모델 설정 연결 테스트 🔗 PersonaBind 캐릭터 프리셋 관리 페르소나 프리셋 관리

시작하기

순서대로 눌러서 진행하세요. 각 단계를 펼치면 자세한 설명이 나옵니다.

1플러그인 설치▾
다운로드한 CharAssist.js 파일을 RisuAI 플러그인 설정에서 가져오기로 불러옵니다. 채팅 화면 메뉴의 🛠️ CharAssist 버튼 또는 플러그인 목록의 CharAssist Settings를 눌러 창을 엽니다.
2AI 공급자 설정▾
사이드바 ⚙️ 설정에서 공급자(Cerebras · Gemini · Vertex AI · GemTi)를 고르고 API 키와 모델명을 입력합니다. 입력 후 🔌 연결 테스트로 즉시 확인하세요.
3캐릭터 선택▾
사이드바 하단 캐릭터 드롭다운에서 편집할 캐릭터를 고릅니다. 기본값인 자동 감지는 RisuAI에서 현재 열어둔 캐릭터를 따라갑니다. 폴더 안의 캐릭터도 목록에 표시됩니다.
4탭 선택 후 항목 고르기▾
설명 · 로어북 · 정규식 · 트리거 · 페르소나 탭 중 하나를 선택합니다. 로어북·정규식·트리거는 목록에서 항목을 고르거나 ➕ 새 항목으로 새로 만듭니다.
5요청 작성 → AI 실행▾
원하는 방향을 요청사항에 적고 ✨ AI 실행을 누릅니다. 비워두면 전반적인 품질 개선을 요청합니다. 결과가 나오면 🖍 변경 부분 보기로 달라진 곳만 확인하세요.
6결과 수정 → 이어서 개선▾
결과 텍스트박스에서 직접 수정할 수 있습니다. 추가 요청을 입력하고 ✨ 이어서 개선을 누르면 현재 결과를 바탕으로 다시 다듬습니다. 만족할 때까지 반복할 수 있습니다.
7적용 · 되돌리기▾
✅ 캐릭터에 적용을 누르면 즉시 저장됩니다. 생각이 바뀌면 ↩️ 되돌리기로 적용 이전 상태로 언제든 복원할 수 있습니다.
8참고범위로 일관성 챙기기▾
사이드바 📌 참고범위에서 체크한 항목이 AI 요청에 함께 전달됩니다. 예를 들어 설명과 로어북을 체크하면, 로어북 수정 시 캐릭터 설명과 어긋나지 않도록 AI가 참고합니다.
9이미지 갤러리 & PersonaBind 설정▾
🗂️ 이미지 갤러리 탭에서 이미지를 업로드하면 페르소나 탭에서 아이콘으로 선택할 수 있습니다. ⚙️ 설정 탭 > 🔗 PersonaBind에서 채팅 입력창에 이름·이미지 위젯 표시 여부와 자동 고정을 설정하세요.

팁

알아두면 더 편해지는 것들.

🗂️

이미지 갤러리 먼저 — 페르소나에 이미지를 설정하려면 🗂️ 이미지 갤러리 탭에서 먼저 업로드해야 합니다. 갤러리에 이미지가 있으면 페르소나 탭 저장 화면에서 바로 선택할 수 있습니다.

🔗

PersonaBind 위젯 — 설정 탭 > PersonaBind에서 이름·이미지 위젯을 켜두면, 채팅 입력창에 현재 페르소나가 표시됩니다. 채팅에 바인드된 페르소나가 있으면 그 페르소나를 우선 표시합니다.

🎭

페르소나 직접 편집 — 페르소나 탭 > 기존 편집 모드에서 리수 페르소나를 선택하면 현재 내용을 불러옵니다. AI로 개선하거나 텍스트박스에서 직접 수정 후 💾 이 내용으로 저장을 누르면 바로 반영됩니다.

⭐

즐겨찾기 요청 — 요청 입력창 옆 ⭐ 저장을 누르면 해당 문구가 즐겨찾기에 등록됩니다. 이후 드롭다운에서 바로 불러올 수 있어 반복 작업이 훨씬 빠릅니다.

📋

캐릭터 · 페르소나 프리셋 — 설정 탭에서 직접 프리셋을 추가하거나 편집할 수 있습니다. 페르소나 프리셋에는 {{char}}, {{description}}, {{user}} 변수를 사용할 수 있습니다.

🧩

정규식·트리거는 JSON 확인 필수 — AI 결과도 JSON 구조를 유지하지만, 적용 전에 형식이 올바른지 한 번 확인해주세요. 편집기에서 직접 수정도 가능합니다.

🌐

영문 번역 — 설명과 로어북 탭에서 원본을 번역하거나, AI 결과를 바로 번역할 수 있습니다. 번역 결과를 직접 캐릭터에 덮어쓰거나 클립보드로 복사할 수 있습니다.

지원 공급자

원하는 AI 공급자를 선택하고, 모델명은 직접 입력할 수 있습니다. GemTi는 리프레시 토큰으로 연결합니다.
