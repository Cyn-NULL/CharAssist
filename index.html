CharAssist

AI가 다듬고, 당신이 결정한다.

캐릭터의 설명(Description), 로어북, 정규식, 트리거를 AI와 함께 지능적으로 수정하고 관리할 수 있도록 돕는 전문 편집 도구입니다. 무엇이 바뀌었는지 한눈에 보여주고, 마음에 들지 않으면 언제든 되돌릴 수 있습니다.

주요 기능

편집부터 검토, 되돌리기까지 하나의 흐름으로.

🗂️

4개 탭에서 관리

캐릭터 설명, 로어북 항목, 정규식 스크립트, 트리거 스크립트를 각각의 탭에서 관리합니다. 원본을 먼저 확인하고, 원하는 방향을 요청하고, AI가 다듬은 결과를 검토한 뒤 적용합니다.

🖍

바뀐 부분이 한눈에 보이는 하이라이트

AI가 손을 댄 부분은 형광펜으로 칠한 것처럼 표시됩니다. 결과 전체를 처음부터 다시 읽지 않아도, 무엇이 달라졌는지 바로 파악할 수 있습니다.

↩️

되돌리기

적용은 늘 되돌릴 수 있습니다. 마음에 들지 않으면 한 번의 클릭으로 적용 이전 상태로 복원됩니다.

💾

작업 내용 보존

창을 닫아도 AI가 만든 결과와 입력했던 요청사항은 사라지지 않습니다. 나중에 다시 열어 이어서 검토할 수 있습니다.

⭐

즐겨찾는 요청 문구

자주 쓰는 요청("더 신비롭게", "간결하게 다듬어줘" 등)을 즐겨찾기에 저장해두고 어느 탭에서든 바로 불러와 씁니다.

➕

새 항목 만들기

로어북·정규식·트리거는 빈 항목을 만들고 원하는 내용을 요청하면, AI가 처음부터 초안을 작성해줍니다.

🔌

여러 AI 공급자 지원

Cerebras, Google AI Studio(Gemini), Vertex AI 중에서 선택할 수 있고, 모델명은 직접 입력할 수 있어 최신 모델이 나와도 바로 사용할 수 있습니다.

📌

참고범위 지정

설명을 고칠 때 로어북 내용을 참고하게 하는 등, 다른 영역의 정보를 함께 참고하도록 범위를 지정할 수 있습니다. 일관성 있는 결과를 얻는 데 도움이 됩니다.

시작하기

순서대로 눌러서 진행하세요. 각 단계를 펼치면 자세한 설명이 나옵니다.

1열기▾
채팅 화면 메뉴의 🛠️ CharAssist 또는 플러그인 설정 목록의 CharAssist Settings를 누르면 창이 열립니다.
2AI 공급자 설정▾
사이드바의 ⚙️ 설정에서 사용할 공급자를 고르고 정보를 입력합니다. 모델명은 자유롭게 입력할 수 있습니다. 입력 후 🔌 연결 테스트로 바로 작동 여부를 확인해보세요.
3캐릭터 선택▾
사이드바 하단에서 캐릭터를 고릅니다. 기본값인 자동 감지는 RisuAI에서 현재 열어둔 캐릭터를 그대로 따라갑니다. 특정 캐릭터로 고정하고 싶다면 목록에서 직접 선택하세요.
4원하는 항목 편집▾
사이드바에서 설명 / 로어북 / 정규식 / 트리거 중 하나를 선택합니다. (로어북·정규식·트리거는) 편집할 항목을 목록에서 고르거나, ➕ 새 항목으로 새로 만듭니다.
5요청사항 작성▾
원하는 방향을 요청사항에 적습니다. 비워두면 전반적인 품질 개선을 요청합니다. ✨ AI 실행을 누릅니다.
6결과 확인▾
🖍 변경 부분 보기로 달라진 곳만 따로 볼 수 있고, 텍스트박스에서 직접 다듬을 수도 있습니다.
7적용하기▾
마음에 들면 ✅ 캐릭터에 바로 적용을 누릅니다. 생각이 바뀌면 ↩️ 되돌리기로 언제든 이전 상태로 복원할 수 있습니다.
8참고범위로 일관성 챙기기▾
사이드바 하단 📌 참고범위에서 체크한 항목은, 다른 항목을 편집할 때 함께 참고됩니다. 예를 들어 설명과 로어북을 함께 체크해두면, 로어북을 고칠 때 캐릭터 설명과 어긋나지 않도록 AI가 참고합니다.

팁

알아두면 더 편해지는 것들.

  • 요청사항 입력창 옆 ⭐ 저장으로 자주 쓰는 문구를 즐겨찾기에 등록해두면 다음부터는 드롭다운에서 바로 고를 수 있습니다.
  • 정규식·트리거는 JSON 형태로 표시됩니다. AI 결과도 JSON을 유지하니, 최종 적용 전에 형식이 올바른지 한 번 확인해주세요.
